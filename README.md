# Al-Madina — Turkish & Mediterranean Grocery Storefront

A polished ecommerce mockup built with **Next.js + React + Tailwind CSS**.

## Included
- Responsive desktop/tablet/mobile storefront
- Product search and category filters
- Product cards with real food photography via Unsplash image URLs
- Working add-to-basket, quantity controls, favourites and basket drawer
- Demo checkout modal
- Smooth anchor navigation
- Click-to-call phone link
- Direct Google Maps pinned-search link for:
  **Al-Madina Markt, Landwehrstraße 12, 97421 Schweinfurt, Germany**
- Opening-hours/contact section
- Instagram/Facebook external links
- No backend or payment processing; this is a front-end ecommerce mockup

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Notes
The storefront uses remote Unsplash image URLs so the zip stays lightweight. Replace the image URLs in `app/page.tsx` with your own licensed product/store photography when moving from mockup to production.
